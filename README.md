# موقع كوتش أحمد ماهر — تمرين · تغذية · تقرير

لينك واحد لكل العملاء. العميل بيختار: **ست ولا راجل ← تمريني / تغذيتي / تقريري ← الكود**.

## الفولدرات
- `index.html` — الصفحة الرئيسية (القائمة).
- `workout.html` + فولدر `workouts/` — ملفات التمارين المشفّرة.
- `nutrition/` — موقع التغذية (ملف العملاء: `nutrition/data/clients.enc.js`).
- `report.html` + فولدر `reports/` — ملفات التقارير المشفّرة.
- `admin.html` — أدوات الكوتش (صانع التمارين + صانع التقارير). مش ظاهرة للعملاء.

## الرفع على GitHub (أول مرة)
1. اعمل repository جديد اسمه `coach-ahmed` (Public).
2. فك الضغط عن الملف، وارفع **كل اللي جوه الفولدر** (مش الفولدر نفسه) ← Commit changes.
3. Settings ← Pages ← Branch: `main` / `(root)` ← Save.
4. استنى 2–3 دقايق. اللينك: `https://coachahmedmaher-hub.github.io/coach-ahmed/`

## عميل جديد
- **تمرين:** `admin.html` ← صانع التمارين ← ارفع الملف في `workouts`.
- **تقرير:** `admin.html` ← صانع التقارير ← ارفع الملف في `reports`.
- **تغذية:** بدّل `nutrition/data/clients.enc.js` بالملف الجديد.
- نفس الكود ممكن يفتح التلاتة.
